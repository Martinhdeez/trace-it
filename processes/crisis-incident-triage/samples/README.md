# Crisis incident samples

Upload these PDFs to the `Crisis incident triage` process. Each report uses the labels
the process currently extracts from documents.

| File | Expected outcome |
| --- | --- |
| `incident-monitor.pdf` | `MONITOR` |
| `incident-dispatch.pdf` | `DISPATCH` |
| `incident-escalate-no-unit.pdf` | `ESCALATE` |
| `incident-unconfirmed.pdf` | `ESCALATE` |

The `.page` files are the small text sources used to regenerate the PDFs with `mutool create`.
